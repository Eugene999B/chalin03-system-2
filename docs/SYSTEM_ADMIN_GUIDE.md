# System Admin Guide

Chalin 03 Group Operations Platform is completed here as a local-only handover package for Spare Parts, Mining Operations and Equipment Hire.

Administrators can:

- manage central users and workspace assignments;
- view Audit Trail and System Operations;
- download full system backups;
- run restore dry-runs;
- restore through the web only when `ALLOW_WEB_RESTORE=true` is deliberately set for a local restore window.

Never use this package to connect to Railway, deploy, push, merge or reset the normal `chalin03_db` automatically.
