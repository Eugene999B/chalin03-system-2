# Equipment Installment Finance — Simplified Workspace Release

Date: 2026-08-06

## User experience rule

Every operational page now follows the same sequence:

1. Search or filter.
2. Select the correct customer, application or agreement.
3. Open the focused details or action dialog.
4. Commit only the intended action.

No customer or agreement is automatically opened merely because it is the first record returned by the API.

## Simplified pages

- Finance Customer Centre
- Customer Installment Profiles
- Agreement Activation
- Opening Deposit & Machine Reservation
- Active Installments
- Payments & Collections Centre
- Finance Document Centre

## Document watermark

The official logo and document-type watermark remain present as a subtle background security mark. The foreground overlay introduced in the previous visibility correction was removed because it was too bold and competed with document content.

## Safety

This release changes presentation and selection flow only. It does not change Finance agreements, payments, schedules, reconciliation, machine locks, customer identity, document snapshots or database records.
