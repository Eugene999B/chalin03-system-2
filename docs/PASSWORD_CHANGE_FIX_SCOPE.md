# Password Change Fix Scope

Target branch: `main`

Affected runtime paths:

- `POST /api/auth/change-password`
- browser Axios response handling for `/auth/change-password`

Affected users:

- original System Administrator
- administrators and managers
- accountants, auditors, cashiers and other authenticated staff

Unaffected business data:

- Spare Parts
- Mining Operations
- Equipment Sales & Hire
- customers, products, sales, stock, payments, reports and documents
